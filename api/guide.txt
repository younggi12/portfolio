기술: React 19, React Router, Zustand, Vite, SCSS Modules, Firebase Auth, Firebase Firestore.
문제 해결: 인트로 영상이 끝난 뒤 나타나는 섹션은 스크롤 등장 애니메이션이 실행되지 않았습니다. useEffect가 실행될 때는 아직 섹션이 없어서 ref가 비어 있었고 IntersectionObserver가 연결되지 않았기 때문입니다. callback ref로 요소가 생기는 순간 연결하는 useReveal 훅을 만들어 해결했습니다. 배운 점: 요소가 나중에 생기는 경우엔 useRef + useEffect보다 callback ref가 정확하다. 결과: 인트로 뒤 섹션의 스크롤 등장 애니메이션 동작 0% → 100%.
개선할 점: 글 전체를 한 번에 구독하고 있어서 글이 많아지면 limit · startAfter로 페이지 단위로 불러와야 하고, 실시간 구독(onSnapshot)에 실패 처리를 넣어 "불러오는 중"에서 멈추지 않게 하고, 삭제 확인 · 안내를 브라우저 기본 창(confirm · alert) 대신 사이트에 맞춘 모달로 바꾸고 싶습니다.
