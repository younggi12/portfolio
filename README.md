# 이영기 포트폴리오

**디자인을 코드로, 화면을 경험으로.**
프론트엔드 개발자 이영기의 포트폴리오 사이트입니다. 팀 프로젝트 2개, 개인 프로젝트 4개를 소개합니다.

🔗 **https://younggi-portfolio.vercel.app**

## 볼거리
- **첫 화면** — Three.js로 만든 3D YG가 스크롤에 따라 채워지고, 다 채워지면 글자 속으로 들어가며 다음 장면으로
- **이름 소개** — HELLO I'M → YG → YOUNG GI가 저절로 이어지고, 휠 한 번에 커튼이 걷히며 교육 과정 · 소개 · 배운 기술
- **작품 소개** — 한 화면에 작품 하나, 마우스를 올리면 사이트 전체 스크롤 미리보기 또는 시연 영상 + 그 사이트 헤더 색의 기술 패널
- **작품 상세** — 표지 · 내가 만든 기능(사진 · 실제 코드) · 문제 해결(결과 수치) · 개선할 점 · 팀 기획 문서 내려받기
- **챗봇** — 오른쪽 아래 YG 버튼, 수업에서 배운 키워드 RAG로 이 사이트 내용만 근거로 제가 답하듯 대답
- 부드러운 휠 스크롤, 점 커서, 스크롤 등장 연출 / "동작 줄이기" 설정이면 연출 없이

## 기술 스택
React 18 · Vite 5 · React Router 7 · SCSS Modules · Three.js · GSAP · OpenAI API(Vercel 서버 함수)

## 실행
```bash
npm install
npm run dev      # 개발 서버
npm run build    # 배포용 빌드
```

## 내용 수정 위치
| 바꾸고 싶은 것 | 파일 |
| --- | --- |
| 이름 · 소개 · 사진 · 교육 과정 · 배운 기술 · 연락처 | `src/data/profile.js` |
| 작품 (목록 · 상세) | `src/data/projects.js` + 이미지 `src/assets/images/projects/` |
| 메뉴 · 제목 · 버튼 문구 | `src/data/site.js` |
| 색 · 글자 크기 · 간격 | `src/styles/_variables.scss` |

작업 규칙은 [`AGENTS.md`](./AGENTS.md), 작품 설명 원본은 [`docs/PROJECTS_CONTENT.md`](./docs/PROJECTS_CONTENT.md)에 있습니다.

## 구현 포인트
| 무엇을 | 어떻게 | 결과 |
| --- | --- | --- |
| 3D 첫 화면 | Three.js로 YG를 선 → 면으로 채우고, 다 채우면 글자 속으로 카메라 이동 | 스크롤만으로 첫 장면 → 이름 장면이 끊김 없이 이어짐 |
| 커튼 전환 · 메뉴 이동 | 장면을 시간으로 진행하고 휠 한 번에 커튼, 메뉴 이동 중에는 장면 잠금을 풀어 그대로 통과 | 헤더 메뉴로 작품까지 바로 이동 |
| 부드러운 스크롤 | 휠 · 메뉴 이동을 한 엔진(`useSmoothScroll`)으로 처리, 이동 중 위쪽 높이가 바뀌어도 목표를 다시 계산 | 메뉴 이동이 중간에 멈추던 문제 해결 |
| 키워드 RAG 챗봇 | `api/guide.txt`를 단원으로 나누고 질문과 겹친 표현 길이로 점수 → 상위 3개만 OpenAI에 | 질문당 보내는 자료 약 70% 감소 |
| 문서 · 영상 용량 | Figma 화면설계서 PDF를 이미지 압축, 시연 영상 1200×600 무음 mp4 | 화면설계서 75MB → 11MB |

## 챗봇 설정
`.env.local`(로컬)과 Vercel 환경 변수에 `OPENAI_API_KEY`를 넣습니다. `VITE_` 접두사를 붙이지 않습니다(붙이면 브라우저에 노출).

## 배포
Vercel — `main` 브랜치에 push하면 자동 배포됩니다.
